# ADR-0004：版本基线：JDK 17 + Spring Boot 3.4.1

- 状态：已采纳
- 日期：2026-11-24

## 背景

需要确定后端的语言与框架版本。

## 决定

- **JDK 17**：企业环境普遍支持的 LTS 版本；
- **Spring Boot 3.4.1**：Spring Boot 3.x 的最低要求就是 Java 17，搭配 Jakarta EE 10、Jackson 2。

## 影响与约束

| 项 | 处理 |
|---|---|
| 没有虚拟线程（JDK 21 才正式） | Agent 回合、工具执行使用有上限的线程池；接口设计不暴露线程模型，升级 21 时只换执行器 |
| `switch` 模式匹配在 17 中是预览特性 | 不使用；用 `instanceof` 模式匹配代替 |
| Spring Boot 3.4.x 开源维护已结束 | 教程以 3.4.1 为基线；正式发布前评估升级到仍在维护的版本。内核与插件不依赖 Spring，升级只影响 `liharness-app` |

## 备选方案

- **JDK 21 + Spring Boot 3.5 / 4.x**：有虚拟线程与更长的维护期；但团队环境以 JDK 17 为主。
- **JDK 25**：最新 LTS，部分企业环境尚未普及。

## 后果

- 依赖与资料兼容性最好，团队上手成本最低
- 需要在发布前关注 Spring Boot 的安全补丁情况
