# ADR-0006：存储：H2 文件库 + 追加式会话事件日志

- 状态：已采纳
- 日期：2026-11-24

## 背景

需要持久化：会话、对话历史、模型配置，以及第二阶段的插件启用状态。希望支持会话恢复、回放与问题排查。

## 决定

1. 使用 **H2 文件数据库**（嵌入式，单文件，零运维），表结构由 **Flyway** 管理；
2. 会话内容以**追加式事件日志**存储：每条用户输入、模型输出、工具调用、审批决定、压缩都是一条只增不改的事件；会话的“当前历史”由事件日志推导；
3. 数据访问通过 `liharness-core` 中的 `SessionStore` 接口，`liharness-app` 里的 `H2SessionStore` 是默认实现（属于内核，不开放给插件替换，见 ADR-0007）；
4. API Key 不进数据库，存放在系统钥匙串。

## 备选方案

| 方案 | 不选的原因 |
|---|---|
| JSON 文件 | 简单，但缺少事务与查询能力，多会话并发写入需要自己处理 |
| SQLite | 同样合适；H2 是纯 Java，无需本地库，跨平台打包更省心 |
| 只存“当前历史” | 无法回放、无法排查“模型当时看到了什么” |

## 后果

好的：
- 会话可回放、可审计，便于排查与评测
- 压缩不会丢失原始记录（压缩本身也是一条事件）

坏的：
- H2 文件锁要求同一时间只有一个进程打开数据库（见 ADR-0005 的遗留进程回收）
- 事件日志会持续增长，需要提供归档 / 清理
